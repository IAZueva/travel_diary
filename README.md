# TravelNotes — дневник путешествий

Регистрация пользователей, общая лента и карточки записей, создание/редактирование/удаление своих путешествий, поиск, место с GPS-координатами, URL фотографии, бюджет и перечень достопримечательностей. Координаты можно получить из браузера с разрешения пользователя и открыть на OpenStreetMap.

## Запуск
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Открыть http://127.0.0.1:5000. Зарегистрируйте пользователя, добавьте запись, укажите локацию, фото и расходы, затем проверьте отображение публичной карточки в другом аккаунте.

**Важно:** фотография указывается ссылкой на открытый HTTP(S)-адрес; загрузки локальных файлов пока нет. Геопозиция работает на `localhost` либо HTTPS после разрешения браузера. Для реальной публикации задайте собственный `SECRET_KEY`, включите CSRF, HTTPS и контроль URL/контента. Личная база SQLite в GitHub не публикуется.
